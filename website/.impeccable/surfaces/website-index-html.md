# Surface brief — `website/index.html`

## Scope and visitor mode

**Persuade.** The marketing surface for `emb`. This brief covers one additive
section — the merged capability region and its console placeholder — not the
page. The poster composition, hero, pipeline, terrain, masthead, and footer are
out of scope and must not move.

## Audience, job, and action

Backend, platform, and application engineers who already operate Redis and must
believe, in under a minute, that `emb` drops into the stack they have. Their job
on this section: see the interface they would actually type, understand what it
beyond-embeddings does, and leave for the install command. Primary action is the
existing hero CTA; this section removes the reason to hesitate.

## Proof and content

Every line is repository-sourced. The console replays real transcripts:
`redis-cli EMB minilm "hello world"` → raw float32; `redis-cli -3 EMB minilm
VALUES "hello world"` → the `dtype`/`shape`/`values` envelope; and
`EMB.SCRIPT LOAD` → `EMB.EVSHA` → a labeled classifier reply. The `emb-top`
panel carries the dashboard's real render. Ruled entries cover protocol, script
inference, operations, and the dashboard. No invented number, model, or reply.

## Chosen direction and memorable moment

**The console is the SERVE plate turned to face the reader.** A dark panel built
from the plate's own black top face and `p-fine` lattice, entered by the orange
signal at the established axis. The memorable moment is the second mode: the
same connection that returned bytes answers as a classifier, because a script
was loaded into it.

## Constraints

- Inherit the world. No concept tournament, no replacement identity, no
  `DESIGN.md` rewrite.
- Atoms only: `rule-head` + rule, ruled entries, plates, the signal axis, the
  annotation form. No cards, gradients, radii, or decorative shadows.
- Body font 12px desktop / 14px mobile floor applies to the new dark surface
  too, and its contrast is measured against its own background.
- Placeholder only: real form controls, a `exec(command) → Promise<lines>`
  adapter seam, deterministic transcripts, and zero network calls.
- `prefers-reduced-motion` collapses playback. The region must read with
  JavaScript disabled.
- No hosted endpoint, no live service, no benchmark number without provenance.

## Unresolved decisions

- Exact `rule-head` wording.
- Whether the console sits beside or below the ruled entries.
- Whether `emb-top` is a sibling panel or shares the console's dark surface.

All three use the same atoms and change nothing else.

## Direction contract

THESIS: This section's one idea is that the protocol is the integration, shown
rather than asserted. It refuses the category default of a three-card feature
grid by keeping the poster's ruled-entry form and letting a dark plate carry the
only interactive thing on the page.

OWN-WORLD: The palette is unchanged — `#F3F0E8` paper, `#0B0B0B` ink, `#FF5A1F`
as surface, `#C23D00` as ink-accent — and the component language is the poster's:
hairline rules, tracked mono labels, isometric plate faces (`#111110`,
`#292823`, the `p-fine` lattice). With all content removed, the remaining
object is a ruled list beside a black parallelogram slice.

STORY: The visitor understands that any Redis client already speaks this, that a
script can make the same server answer as a classifier, and that operating it
uses commands they already know. They leave for the install line with no second
service to evaluate.

FIRST VIEWPORT: After the terrain, a `rule-head` with its hairline rule spans the
prose column; below it the ruled entries run in the left column while the dark
console panel sits in the right column, its top-left corner sitting on the
signal axis the pipeline used (`40.7% − --plate/2`). The `emb-top` render is a
second, quieter dark panel beneath it. The console's input is the only control,
and it sits at the panel's foot, full width.

> **Amended during the build.** `emb-top` moved out of the right column and
> became a full-width band closing the section. The capture's longest line is
> ~100 characters; at 1440 the right column is 637px, so the panel could only
> hold it by cutting the output or wrapping the heatmap bars mid-run. The band
> fits it whole and never scrolls at any width. Everything else above stands.

FORM: Extension of an established surface — the poster world. Position on any
ordered list is not applicable and no seed key exists, because `new-work.md` §3
routes a section inside an established surface to inherit rather than to a
tournament; the scope is a local addition, so the roll is deliberately skipped.

FINISH: unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its
provenance.
