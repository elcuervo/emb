III.The languages

One model holds six languages in one space, so a sentence written in English lands where its Portuguese translation lands. No translator runs between them.

One model, many languages: the same meaning lands in the same place whichever language carries it.

THE LANGUAGES · 1 model · 6 languages · 384 dimensions · one space, by meaning

WHAT YOU ARE LOOKING AT

An English-only model puts a French sentence and its English translation in opposite corners of the space, so a search in one language cannot see the other. A multilingual model is trained so meaning lands together no matter which language carries it.

Below, five translations of one sentence and two unrelated sentences are each compared with the English original. The translations should score near each other and well above the unrelated pair. No translator runs: the model reads all six languages itself.

WHAT JUST HAPPENED

Each candidate went to the sandbox as its own EMB.EVSHA multilingual <embed.lua sha1> 1 "<candidate>" "<english>" call: the server embedded both texts through the multilingual model and returned the cosine. One model, one script, one space.

Nothing was translated or transliterated. The tokenizer splits each language into its own subwords, and training pushed translations of a sentence to the same point — which is why the five translations cluster and the other two fall away.

WHY IT MATTERS

Retrieval over a multilingual corpus is otherwise a pipeline: detect the language, translate the query, search, translate the result. One shared space makes it the search you already have — a Portuguese document answers an English question.

It also decides which model to keep. A multilingual model is larger and slower than an English-only one, and emb serves several at once, so you pay for the languages you actually answer.

THE EXACT COMMANDS

One command per candidate, all on the same model and the same script. The count is how many texts the script sees; the English original travels as the reference argument.
