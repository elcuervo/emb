I.The similarity

Everything retrieval does is this number, sorted. One cosine over two vectors, not 384 additions you have to read.

FIG. 2 — THE SIMILARITY · — dimensions · one cosine per pair · scripted server-side · no vector on the wire

WHAT YOU ARE LOOKING AT

Two vectors and one cosine. Because the model normalizes what it returns, cosine similarity is the dot product, and the result is a single number with a real meaning: 1 is the same direction, 0 is unrelated, and negative is opposed. A passage and a paraphrase of it sit above 0.6; a passage and an unrelated one sit near 0.1.

The number is computed by the sandbox, not here: the plate calls one of the server's preloaded Lua scripts by its SHA1 and renders the reply. The script's source is printed below the reply, and the digest beside it is the digest of exactly those bytes — a script the sandbox was not told to load is a call it refuses, so the page cannot describe one it does not have.

WHAT JUST HAPPENED

The script calls emb.embed twice — the same embedding path, the same batcher and the same cache as EMB — and then emb.similarity. It returns a hash rather than 768 floats, because the point is the number: a page does not need the vector to answer how close are these.

Doing it in Lua rather than in the page is the product's own argument. The arithmetic runs next to the model, in the server's process, over the same packed float32 buffers the model produced — so a rerank costs one round trip and no bytes on the wire.

WHY IT MATTERS

This is the floor of every vector feature. Deduplication, clustering, retrieval, recommendations, anomaly detection: each is a similarity, an ordering, and a threshold chosen to suit the consequences of being wrong. The next plate sorts this number over 2 782 passages instead of two.

THE EXACT COMMANDS

One command. The count before the texts is the number of texts the script will see; the reference passage travels as an argument, which is also what keeps the reply cacheable per pair. 

EMB.EVSHA minilm <embed.lua sha1> 1 "first passage" "second passage"
# -> { dim = 384, norm = 1, similarity = 0.42 }
