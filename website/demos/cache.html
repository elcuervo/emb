III.The cache

Ask once, ask again. emb keys a vector by the model, the text and the settings, so the second ask is a lookup — not a second pass over the model.

The same text always gives the same vector, so the server keeps it. Asking twice is a lookup, not a second model run.

THE CACHE · — hit rate · — entries · — dimensions · server-side timing

WHAT YOU ARE LOOKING AT

Embedding the same text twice is work a server does not have to do twice. The vector is a pure function of model and text: the same bytes in always produce the same 384 floats out. That makes it safe to remember, and emb remembers it in an LRU bounded by a memory budget.

The plate asks for one passage twice and reads the model's own cache counters around the pair. Type your own passage and the first ask is a miss, the second a hit; if someone already asked for this exact passage, the first is a hit too — and the plate says so, because the counters are the server's.

WHAT JUST HAPPENED

Two identical EMB commands went to the sandbox with an EMB.INFO before and after each. The first call either missed and filled the cache or was already a hit; the second was a hit either way. cache_hits moved by at least one.

Nothing on the page arranged this. There is no warm-up step and no CACHE GET to call: every path — EMB, EMB.MULTI, a preset's emb.embed — reads and writes the same cache.

WHY IT MATTERS

Real traffic repeats itself: a search box re-asks as someone types, a queue retries, a corpus is re-indexed and half the documents have not changed. A cache turns every repeat from inference into a memory read — no new hardware, no smaller model, no loss of quality, because it returns the same vector, not an approximation.

It is also why the gallery can afford to be live. Every plate runs against one shared 2 GB machine, and the canned queries are cached after their first reader, so a room full of visitors mostly reads memory.

THE EXACT COMMANDS

The counters are part of the model's own info, so the claim is checkable from any client. A repeat across two visitors is a hit for the second.
